# Ajedrez Flat UI — Nanai Pro

Motor de ajedrez completo en un solo archivo HTML.

## Características

- Reglas oficiales (enroque, al paso, promoción, jaque, mate, ahogado)
- IA con Minimax + Alpha-Beta + Piece-Square Tables (3 niveles)
- Historial de jugadas en notación algebraica (SAN)
- Drag & Drop + click para mover
- Jugar con Blancas o Negras vs IA
- Modos: 1 vs IA · 1 vs 1 · IA vs IA
- Exportar / Importar FEN
- Exportar PGN
- Regla de las 50 jugadas y triple repetición
- Detección mejorada de material insuficiente
- Sonidos Web Audio API
- Diseño Flat UI "Nanai" (tema granate/dorado)
- Responsive y sin dependencias externas (excepto Tailwind CDN)

## Demo

https://cristianrivano.github.io/ajedrez-nanai/

Abre `index.html` en cualquier navegador moderno.
